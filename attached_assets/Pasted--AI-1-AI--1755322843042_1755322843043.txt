# マンション管理規約改訂分析AIエージェントシステム設計書

## 1. システム概要

マンション管理規約の改訂を効率化するAIエージェントシステム。法改正情報、標準管理規約、過去の議事録を基に、改訂が必要な箇所を自動抽出し、改訂案を生成する。

### 主要機能
- 規約改定分析の自動実行
- 改訂必要箇所の差分抽出
- 改訂詳細の根拠付き提案
- AIエージェントタスク管理
- 分析結果の時系列管理

## 3. AIエージェント設計

### 3.1 規約分析エージェント

#### 3.1.1 エージェント仕様
**エージェント名**: 規約分析エージェント (RegulationAnalysisAgent)
**主要機能**:
- 法改正情報の自動取得・解析
- 標準管理規約との差分分析
- 過去議事録からの未反映事項抽出
- 改訂優先度の自動判定

#### 3.1.2 分析プロンプト設計

**システムプロンプト**:
```
# 規約分析エージェント v2.0

## ロール定義
あなたは、マンション管理規約の改訂分析を専門とするAIエージェントです。
法的知識、標準管理規約、過去の決議履歴を総合的に分析し、
改訂が必要な箇所を正確に特定します。

## 分析対象
対象マンション: メゾンドオプテージ
管理規約: メゾンドオプテージ管理規約

## 分析能力
- 法改正情報と現行規約の整合性チェック
- 標準管理規約改定内容との比較分析
- 過去決議事項の規約反映状況確認
- 改訂優先度の客観的評価
- 実装期限の合理的設定

## 品質基準
- 分析精度: 95%以上
- 法的根拠の明確化: 必須
- 誤検出率: 5%以下
- 処理時間: 15分以内
```

**分析実行プロンプト**:
```
## 分析タスク実行

### 入力データ
- 現行管理規約: {current_regulation}
- 分析設定: {analysis_settings}
- 法改正情報: {law_updates}
- 標準管理規約: {standard_regulation}
- 過去議事録: {meeting_minutes}

### 分析手順
1. **差分抽出フェーズ**
   - 既存分析結果との比較
   - 新規項目の特定
   - 変更項目の更新

2. **法令適合性チェック**
   ```
   FOR EACH 法改正事項 IN 法改正情報:
     IF 現行規約 NOT COMPLY WITH 法改正事項:
       ADD TO 改訂必要項目
       SET 優先度 = "高"
       SET 根拠 = 法改正事項.詳細
   ```

3. **標準規約適合性チェック**
   ```
   FOR EACH 条項 IN 標準管理規約:
     IF 現行規約.条項 DIFFERS FROM 標準管理規約.条項:
       EVALUATE 改訂必要性
       IF 改訂必要:
         ADD TO 改訂必要項目
         SET 優先度 = CALCULATE_PRIORITY(差異度, 影響度)
   ```

4. **過去決議事項チェック**
   ```
   FOR EACH 決議 IN 過去議事録:
     IF 決議.内容 NOT REFLECTED IN 現行規約:
       ADD TO 改訂必要項目
       SET 優先度 = BASED_ON 決議.重要度
   ```

### 3.2 評価・モニタリング機能

#### 3.2.1 リアルタイム評価指標
- **処理精度**: 手動検証結果との一致率
- **処理速度**: 設定された目標時間との比較
- **新規発見率**: 前回分析からの新規項目割合
- **誤検出率**: 後日判明した誤分析の割合

#### 3.2.2 学習・改善機能
- **フィードバック収集**: ユーザーの採用/却下情報
- **精度向上**: 分析結果の正確性向上のための学習
- **処理最適化**: 実行時間短縮のためのアルゴリズム調整

    start_time TIMESTAMP,

    status VARCHAR(20),
    settings JSON,
    performance_metrics JSON,

## 5. 運用・保守計画

### 5.1 定期更新スケジュール
- **法改正情報**: 月次自動取得
- **標準管理規約**: 国交省発表時に即時更新
- **エージェント学習**: 週次バッチ処理
- **精度評価**: 月次レポート生成

### 5.2 障害対応
- **分析失敗時**: 自動リトライ機能
- **データ取得エラー**: アラート通知
