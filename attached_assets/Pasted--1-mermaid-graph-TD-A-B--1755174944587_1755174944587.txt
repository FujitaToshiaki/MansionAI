```mermaid
    D --> E[OCR処理・確認画面]
```

## 2. 詳細画面設計

### 画面1：マンション一覧画面（メイン画面）
**目的：** 管理会社が担当する全マンションの状況を一覧で把握

#### 画面レイアウト
```
┌─ヘッダー─────────────────────────────────────┐
│ [管理規約AI] [通知:5] [田中太郎様] [ログアウト]     │
├─────────────────────────────────────────┤
│┌サイドメニュー┐│ マンション一覧                │
││ダッシュボード││                              │
││マンション管理││ [検索ボックス] [フィルター▼] [新規登録] │
││標準規約参照 ││                              │
││レポート機能 ││┌─一覧テーブル────────────────┐│
││システム設定 │││マンション名│所在地│戸数│管理開始│法改正│││
│└────────┘││            │      │    │日    │対応│││
│              ││────────┼──────┼────┼────┼────│││
│              ││パークヒルズA│○○区  │120 │2020/4│◯完了│││
│              ││グランマンションB│××市│85  │2018/1│△進行│││
│              ││サンライズC│△△町│200 │2015/3│×未着手││
│              ││レジデンスD│▽▽区│95  │2022/6│-対応不要││
│              │└─────────────────────────┘│
│              │ページネーション: [1][2][3]...[次へ]     │
└─────────────────────────────────────────┘
```

#### 主要機能
- **一覧表示項目：**
  - マンション名（クリックで詳細画面へ）
  - 所在地・戸数・築年数
  - 管理開始日・契約状況
  - 法改正対応ステータス（◯完了・△進行中・×未着手）
  - 最終活動日・担当者
  
- **フィルター・検索機能：**
  - 法改正対応状況（◯完了・△進行中・×未着手・-対応不要）
  - 管理開始年
  - 戸数範囲
  - 担当者
  - 築年数
  - 所在地域

- **ソート機能：**
  - 法改正対応優先度順
  - 管理開始日順
  - 最終更新日順

## 4. 拡張機能の動作仕様

### A. ステータス管理の詳細
- **◯完了：** 法改正対応が完了済み
- **△進行中：** 改訂作業が進行中
- **×未着手：** まだ対応に着手していない
- **-対応不要：** 法改正の影響なし（新築、特殊規約等）

### B. チャット・音声入力機能の特徴
1. **自然言語による指示**
   - 「もう少し厳格に」「標準規約に合わせて」等の曖昧な指示も理解
   - 条文番号や専門用語の自動補完

2. **リアルタイム処理状況表示**
   - エージェントの思考過程を可視化
   - 処理時間の予測と進捗表示
   - エラー時の自動復旧状況

3. **対話的な確認プロセス**
   - 変更内容の事前確認
   - 複数案の提示と選択
   - 影響範囲の明示

### C. エージェントタスク管理
1. **タスクの自動分解**
   - 複雑な要求を複数の実行可能タスクに分割
   - 依存関係の自動解析
   - 優先度の動的調整

2. **実行履歴の完全記録**
   - 全ての処理ステップを記録
   - 意思決定の根拠保存
   - 監査対応の証跡管理

3. **学習機能**
   - ユーザーの修正パターンを学習
   - 頻出する要求の自動化
   - 精度の継続的改善

**従来作業時間：40時間 → 新システム：30分以内（98.8%削減）**

```

     ↓           ↓            ↓           ↓         ↓
   ファイル管理 → テキストDB → 決議履歴DB → 分析結果 → 規約バージョン管理
```

### 状態管理
- **進捗ステータス：** 各段階での完了状況を管理

- **自動保存：** 定期的な作業内容の保存
- **復元機能：** 前の段階への戻り操作
