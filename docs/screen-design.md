## 2. 物件管理（中心機能）

### 2-1. マンション一覧

**スクリーンショット**: `01_condominium_list.png`

![マンション一覧](screenshots/01_condominium_list.png)

**URL**: `/condominiums`  
**画面タイトル**: マンション管理 / マンション一覧

#### 画面概要

登録されているすべてのマンションを一覧表示する中心画面。物件の検索・絞り込み・ソートを行い、各物件の詳細へ遷移するエントリポイント。

#### 画面構成

**ページヘッダー**

| 要素 | 説明 |
|------|------|
| ページタイトル | 「マンション管理」（ページ見出し）、「マンション一覧」（セクション） |
| 新規登録ボタン | 右上「＋新規登録」オレンジボタン |

**フィルタ行**

| 要素 | 内容 |
|------|------|
| 検索 input | マンション名・住所等でテキスト検索 |
| 法改正対応状況 | ドロップダウン（すべて / 完了 / 進行中 / 要着手） |
| 管理開始年 | ドロップダウン（年度フィルタ） |

**テーブル**

| カラム | 内容 |
|--------|------|
| マンション名 | 物件画像サムネイル＋名称＋建築年（「第N期」表示） |
| 所在地 | 都道府県・市区町村・番地 |
| 戸数 | 総戸数（N戸） |
| 管理開始日 | YYYY/M/D 形式 |
| 法改正対応 | バッジ（完了=青 / 進行中=黒 / 要着手=赤） |
| 担当者 | 担当管理者名 |
| 最終活動日 | 最終更新日付 |
| アクション | 「詳細」「編集」ボタン |

**ステータスバッジ色**

| バッジ | 色 |
|-------|-----|
| 完了 | 青（bg-blue-100） |
| 進行中 | 黒（bg-gray-800） |
| 要着手 | 赤（bg-red-100） |

**データ**: 最大20件表示（デモデータ）

### 2-2. 物件詳細 — 基本情報タブ

**スクリーンショット**: `02_condominium_detail_basic.png`

![物件詳細（基本情報）](screenshots/02_condominium_detail_basic.png)

**URL**: `/condominiums/:id`（デフォルトタブ）  
**アクティブタブ**: 基本情報

#### 画面概要

選択したマンションの詳細情報を表示。ページ上部の物件ヘッダーと統計カード、続いて5タブ構成の詳細コンテンツで構成される。

#### 物件ヘッダー

| 要素 | 内容 |
|------|------|
| 物件画像 | サムネイル（左上） |
| マンション名 | 大見出し（例：メゾンドオプテージ） |
| 住所 | 都道府県・市区町村・番地 |
| 基本情報行 | 「第N期 / N戸 / 管理開始：YYYY/M/D」 |

#### 統計カード（4枚）

| カード | 表示内容 |
|-------|---------|
| 管理組合理事長 | 担当者名・連絡先 |
| 次回会議・総会 | 開催予定日・終了予定日 |
| 法改正対応状況 | 完了バッジ（青）＋最終対応日 |
| 最近の活動 | 最終活動日付・活動内容 |

#### ヘッダー機能ナビバー

物件詳細ページ専用の機能グループナビ（水平タブ形式）：  
「物件詳細」「議案管理」「議事録管理」「長期修繕計画管理」「管理適正評価」「規約改訂」「問合せ管理」「AIチャット」

#### タブ一覧

| タブ名 | 内容 |
|--------|------|

| 各種専門部会 | 委員会カード一覧 |
| 特記事項 | カテゴリ別特記事項 |
| その他ファイル | 添付ファイル一覧 |

#### 基本情報コンテンツ

| 項目 | 説明 |
|------|------|
| マンション名 | 正式名称 |
| 所在地 | 完全住所 |
| 総戸数 | 例：437戸 |
| 築年数 | 例：第41年（1985年建築） |
| 管理開始日 | 例：2020/4/1 |
| 現行規約拡数 | 例：第5.0版 |

物件詳細のヘッダーナビ「問合せ管理」、またはヘッダーの「AIチャット」ボタンから遷移。

### 3-1. チャット相談

**スクリーンショット**: `07_consultation_chat.png`

![チャット相談](screenshots/07_consultation_chat.png)

**URL**: `/consultation/chat?condominiumId=:id`  
**アクティブタブ**: チャット相談

#### 画面概要

管理業務に関する質問をAIエージェントに相談できる対話型チャット画面。

#### レイアウト（2カラム）

**左パネル（チャットエリア）**

| 要素 | 内容 |
|------|------|
| セクションタイトル | 「AI管理業務相談」 |
| カテゴリフィルタータブ | すべて / クレーム / 法令解釈 / 運用利用 |
| AI挨拶メッセージ | 「こんにちは。管理業務に関するご相談を承ります。どのようなことでお困りでしょうか？」（グレーバブル） |
| メッセージ入力欄 | 下部固定のテキスト入力（「メッセージを入力してください…」プレースホルダー） |
| 送信ボタン | オレンジ丸ボタン（右端） |

**右パネル（サポートエリア）**

| 要素 | 内容 |
|------|------|
| よくある質問 | クリック可能な質問リスト（例：「管事会の議事録作成のコツを教えてください」「相模建立全の改変に必要な手続きは何ですか？」「今月有効における 重大な変更 の定義を教えてください」） |
| AI相談のヒント | ベージュ背景のヒントボックス（「具体的な状況（日時、場所、関係者など）を含めて質問すると、より精確な回答が得られます」） |

**サブナビ**（ページ上部）: チャット相談（アクティブ） / 相談履歴

## 4. 議案管理

### 4-1. 議案一覧

**スクリーンショット**: `09_proposals_list.png`

![議案一覧](screenshots/09_proposals_list.png)

**URL**: `/proposals/list?condominiumId=:id`  
**アクティブメニュー**: 議案一覧

#### 画面概要

総会・理事会に提出予定の議案書を2列カードグリッドで管理する。

#### 次回総会バナー

オレンジ背景のバナーに次回総会情報を表示：  
「2026年10月 第42回定期総会 開催予定日: 2026年10月25日（日）」

#### ページ操作ボタン

| ボタン | 説明 |
|--------|------|
| ＋新規議案追加 | 新しい議案を追加する |

**サブナビ（左メニュー展開）**: 議案一覧 / AI議案書生成 / 議案書編集

#### 議案カード

2列グリッドで表示。各カードの構成：

| 要素 | 内容 |
|------|------|
| 優先度タグ | 緑「規約」/ 橙「管理費」/ 青「工事」/ グレー「その他」 |
| ステータスバッジ | 「審議中」「下書き」等 |
| 議案タイトル | 件名（太字） |
| 説明文 | 概要テキスト（2〜3行） |
| 日付 | 予定日（YYYY/MM/DD） |
| 操作 | 「編集」「詳細 →」リンク |

**議案カード例（10件）**:

| 議案 | カテゴリ |
|------|---------|
| 管理規約の一部改訂（ペット飼育規定・民泊禁止条項追加） | 規約 |
| 大規模修繕工事実施の件（EV更新・外壁塗装） | 工事 |
| 管理費改定の件（月額8,500円→9,000円） | 管理費 |
| 駐車場使用細則の改訂（EV充電設備設置対応） | 規約 |
| 屋上防水工事の実施承認 | 工事 |
| 管理員業務委託契約の更新（株式会社〇〇管理センター） | 総会 |
| 修繕積立金額見直しの件 | 管理費 |
| 防犯カメラ増設工事の件（共用部死角解消） | 工事 |
| 集会室使用細則の改訂（時間延長・利用料見直し） | 総会示 |
| マンション管理適正化診断の受診承認 | その他 |

### 4-2. AI議案書生成

**スクリーンショット**: `10_proposals_generate.png`

![AI議案書生成](screenshots/10_proposals_generate.png)

**URL**: `/proposals/generate?condominiumId=:id`  
**ページタイトル**: 新規議案書作成（AIアシスト）

#### 画面概要

AIを使って議案書の本文・文案を自動生成する画面。左にフォーム、右にAIプレビューが表示される2カラムレイアウト。

#### 左パネル（議案基本情報フォーム）

| フィールド | 種別 | 例 |
|-----------|------|-----|
| 議案タイトル | テキスト入力 | 管理規約の一部改訂について |
| カテゴリ | ドロップダウン | 規約 |
| 決議種別 | ドロップダウン | 特別決議 |
| 要旨・背景 | テキストエリア | 2025年の法改正に合わせ、当マンションの規約も最新の標準規約に準拠させる必要がある。 |

**生成ボタン**: 「AI議案書・文案生成」（オレンジ、フォーム下部）

#### 右パネル（AIプレビューエリア）

フォーム入力前は「左のフォームを入力してAI分析を閲覧してください」プレースホルダー表示。  
生成後は議案書本文・文案が表示される。
