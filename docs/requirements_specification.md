# 第1部: 要件定義書

## 1. システム概要

### 1.1 システムの目的
本システムは、マンション管理会社向けの管理規約AIシステムであり、以下の業務を自動化・効率化することを目的とする：

1. **議事録のデジタル化**: 紙ベースの議事録をOCR技術で電子化
2. **決議事項の自動抽出**: AIを活用して議事録から決議事項を自動識別・分類
3. **規約分析**: 現行規約と標準管理規約の比較分析
4. **改訂案の自動生成**: 法改正や決議事項に基づく規約改訂案の自動生成
5. **令和7年度標準管理規約改正対応**: R7改正項目の追跡と対応状況管理

### 1.2 対象ユーザー

| ユーザー区分 | 役割 | 主な利用機能 |
|------------|------|-------------|
| 管理会社担当者 | マンション管理業務の実務担当 | 全機能 |
| 管理組合理事 | 規約改訂の承認・決定 | 規約閲覧、改訂承認 |
| 法務アドバイザー | 法的妥当性の確認 | 規約分析、法令チェック |
| システム管理者 | システム設定・保守 | 設定、ユーザー管理 |

### 1.3 システムの特徴

- **RAG（Retrieval-Augmented Generation）技術**: 議事録・規約をナレッジベースとして活用
- **マルチAIエージェント**: OCR、決議抽出、規約分析、改訂生成の各専門エージェント
- **令和7年度法改正完全対応**: 25項目のR7改正項目を網羅
- **監査証跡**: 全操作の履歴を保持
